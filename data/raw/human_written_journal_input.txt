My OJT Journal - Pauline (Week 1 to Week 2 Entries)

March 2, 2026 - Monday
First day was mostly about getting settled in at the MIS office. Engr. Santos introduced me to the other interns and showed us where our desks were. In the morning, I spent a lot of time wiping down my desk and getting my workstation ready. My computer was running an old OS, so I had to download Ubuntu and set up my dev environment from scratch. Afterwards, I installed Git so I could pull our project repository from GitHub. In the afternoon, Ma'am Elena from admin gave us a tour of the records room and had us sign some clearance forms and visitor guidelines. We didn't do much coding today, mostly just orientations and reading the company documentation.

March 3, 2026 - Tuesday
Today felt a lot more productive! I paired up with Ken to inspect the department's student records database. The old database was a bit messy with redundant rows, so we started designing clean relational tables in PostgreSQL. Ken showed me some handy SQL queries to check foreign keys. Later in the afternoon, I wrote a quick data migration script using Python to clean up the exported CSV rows and load them into the new schema. Right before 4 PM, Ma'am Sarah asked if I could help her with document stamping and sorting paper requisitions for the accounting office. It took about 45 minutes to finish stamping and filing them into the green folders.

March 4, 2026 - Wednesday
Spent the whole morning building out the student API backend. We decided to write the endpoints using Laravel since the existing system had some PHP legacy code. It went pretty smoothly, although I got stuck on route model binding for about an hour before realizing I had a typo in my migration. In the afternoon, the team lead asked me to review how Spring Boot handles JWT tokens so we could compare performance with our microservices. Around 3:30 PM, I helped the administrative assistant compile the weekly staff attendance log into Microsoft Excel. My eyes were hurting a bit by the end of the day from staring at spreadsheets!

March 5, 2026 - Thursday
Thursday was container day! Our senior engineer told us that running services locally without containers was causing too many "works on my machine" headaches, so I spent the morning learning how to package our web service into a container with Docker. Once that was up and running, I wrote automated test scenarios using Postman to verify that all our CRUD endpoints returned status 200 and proper JSON payloads. Late in the afternoon, I walked over to the registrar's office to assist with student clearance forms and filing folders into alphabetical filing cabinets.

March 6, 2026 - Friday
End of week 1! First thing this morning, we held our weekly team sprint meeting in conference room B. Everyone shared what they completed during the week and what blockers they had. After the meeting, I worked with the DevOps lead to test our automated deployment setup using Jenkins and connected it to our AWS testing server. We also noticed that one of the database queries was taking almost two seconds to resolve, so we implemented Redis caching for the frequently accessed student records. That dropped the query time to under 50 milliseconds! Felt great to wrap up the week on a high note.

March 9, 2026 - Monday
Starting week 2. Today was all about the frontend redesign. Before jumping into code, I opened Figma to review the UI wireframes and interactive mockups that the design team made last week. After getting approval on the layout, I started writing React components with TypeScript. Having type checking definitely caught a couple of null pointer errors early on. Before logging out, I helped our supervisor conduct an inventory counting of spare monitors, keyboards, and mice in the storage closet.

March 10, 2026 - Tuesday
Continued working on the frontend interface today. The backend team exposed some new endpoints, so I hooked them up using GraphQL instead of traditional REST calls to avoid over-fetching data. For the UI styling, we used Tailwind CSS, which made responsive layout adjustments on mobile screens super fast. Around 3 PM, the department secretary asked for assistance in printing, compiling, and distributing copies of an urgent department memorandum across different office desks.

March 11, 2026 - Wednesday
Heavy backend day today. We deployed our test cluster on Kubernetes in the staging environment. Setting up the ingress routing took a little trial and error, but we finally got traffic forwarding correctly. Later, I helped build a background worker script in Node.js connected to RabbitMQ to process bulk email notifications without freezing the web server. In the late afternoon, I was assigned to encode a batch of incoming scholarship application folders into the university database registry.

March 12, 2026 - Thursday
Came in early today because our staging server had an intermittent connection issue. I remoted into the Linux server via SSH, checked the firewall iptables, and analyzed system logs until we figured out a DNS resolution conflict. Once that was fixed, I created an automated Bash script to run nightly database backups and set it up via cron. After lunch, I helped organize outgoing envelopes and handled physical document routing for the department director.

March 13, 2026 - Friday
Finished up week 2! Today we focused on optimizing web server performance. I tuned the Nginx reverse proxy configuration to enable gzip compression and HTTP/2. Afterwards, we ran static code analysis using SonarQube to catch code smells and security vulnerabilities. To end my internship week, I spent the last hour helping the office staff finish their department inventory analysis report and organized the files for the upcoming university accreditation inspection.
